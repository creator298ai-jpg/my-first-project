# Луна и Экадаши

Минималистичный календарь в стиле iOS: экадаши с точным временем **входа** и **выхода (параны)** для выбранного города, а также лунный календарь с отметками 1-го и 15-го лунного дня.

## Возможности

- **Экадаши**: название (по лунному месяцу, включая адхика-масу), день поста, вход (восход Солнца, последняя еда накануне до заката), окно параны.
- Две традиции: **вайшнавская (ИСККОН / GCal)** с правилом арунодаи (96 минут до восхода) и **смарта (как в Drik Panchang)** с Хари-васарой и пратахкалой.
- **Местоположение**: поиск города или GPS; всё время считается в часовом поясе выбранной точки.
- **Лунный календарь**: титхи (ведические лунные дни) или лунные сутки (от восхода Луны), фаза, восход и заход Луны, отметки 1-го и 15-го дня, подсветка дней 1–15.
- **Экспорт в Календарь iPhone** (.ics) с напоминаниями.
- PWA: работает офлайн, ставится на экран «Домой».

## Установка на iPhone

1. Откройте сайт в **Safari**.
2. Нажмите «Поделиться» → **«На экран Домой»**.

## Разработка

```bash
npm install
npm run dev     # локальный сервер
npm test        # сверка с датами Drik Panchang
npm run build   # сборка в dist/
```

Публикация на GitHub Pages происходит автоматически при пуше в `main` (`.github/workflows/pages.yml`).
